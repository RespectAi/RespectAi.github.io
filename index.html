Building for Mobile and the Web

I am a software developer based in Abuja, Nigeria. Most of my work centers on cross-platform mobile apps with Flutter and Dart, along with full-stack web applications using JavaScript, React, and Supabase.

I focus on practical engineering: offline-first local storage, responsive state management, and fast database sync. When building an app, my goal is always to make it fast, reliable, and straightforward to use.
